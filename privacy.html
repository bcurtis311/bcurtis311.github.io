Privacy Policy

Last updated: October 11, 2026

Command Central is a personal tool used only by its owner, Barry Curtis. This policy explains how it handles Google account data.

What it accesses

With the owner's permission, Command Central reads and updates the owner's own Gmail, Google Calendar and Google Drive files (including a task spreadsheet it creates) so it can organize his tasks, schedule and email.

How the data is used

  • Data is used only to provide these features to the owner.
  • Data is processed on the owner's own computers. Sign-in credentials are kept in the operating system's secure keychain.
  • No data is sold, shared with, or transferred to anyone else, and none is used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: use the support email shown on the Google sign-in screen for this app.
